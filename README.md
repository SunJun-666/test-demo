# test-demo

用于测试 Git、GitHub 协作和分支操作的演示仓库。

## 当前内容

当前版本包含以下文件：

- `README.md`：仓库说明与协作流程。
- `task-1.txt`：Issue #1 的协作测试文件，用于验证新增文件、提交和推送流程。

此前的静态首页、样式、交互脚本、素材、预览脚本和旧测试文件已移除，可通过 Git 历史查看。

当前版本没有可运行的应用，也不需要安装依赖。

## 开始使用

```bash
git clone git@github.com:SunJun-666/test-demo.git
cd test-demo
git switch dev
```

日常开发以 `dev` 为基线，在任务分支中修改，通过 Pull Request 提议合入 `dev`。

## 协作流程

1. 创建 Issue，写明任务内容、允许修改的文件、依赖和可核对的验收标准，并设置负责人、标签及适用的里程碑。
2. 从最新的 `dev` 创建任务分支，例如 `codex/issue-1-readme-sync`，只修改任务范围内的文件。
3. 提交变更并创建以 `dev` 为目标的 PR，在描述中用 `Closes #<Issue编号>` 关联任务，同时说明变更及验证结果。
4. 根据实际进度更新 Issue 的任务清单和状态说明；提交草稿 PR 后保留待验收状态。
5. 维护者验收并合并后关闭任务。参与情况依据提交、Issue、PR、评论和 Review 记录核对；分配负责人本身不代表已完成工作。

本仓库的协作测试可由自动化工具代账号执行。统计参与情况时，应区分账号记录、自动化操作与实际人工评审。
